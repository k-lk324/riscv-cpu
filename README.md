# RISC-V Processor Design in Verilog

A university hardware design project developed as part of the Hardware I course at Aristotle University of Thessaloniki.

The project covers the implementation and simulation of several processor components in Verilog, progressing from an arithmetic logic unit to a RISC-V datapath and finite-state control logic.

## Components

| Component | Description |
|-----------|-------------|
| ALU | Arithmetic and logical operations |
| Calculator | ALU-based calculator with button inputs |
| Register File | Register storage with read/write operations |
| Datapath | Instruction decoding and datapath components |
| Processor Control | Finite-state control logic for RISC-V instructions |
